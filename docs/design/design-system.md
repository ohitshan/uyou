# UYOU Design System
Version: 1.1
Last Updated: 2026-07-26
 
---
 
# 개요
UYOU는 외국인을 위한 한국 유학 정보 플랫폼입니다.
사용자는 한국에 익숙하지 않은 외국인이므로,
복잡하거나 화려한 디자인보다 쉽고 직관적인 사용자 경험을 제공합니다.
 
---
 
# 디자인 키워드
- Simple
- Trustworthy
- Modern
- Friendly
- Accessible
- Clean
---
 
# 디자인 원칙
 
## 1. Information First
사용자는 학교 정보를 찾기 위해 방문합니다.
디자인보다 콘텐츠를 우선하며,
불필요한 장식보다 정보 전달을 가장 중요하게 생각합니다.
 
---
 
## 2. Consistency
모든 페이지는 동일한 디자인 규칙을 사용합니다.
- 동일한 컴포넌트
- 동일한 레이아웃
- 동일한 여백
- 동일한 타이포그래피
새로운 UI를 만들기 전에 기존 컴포넌트를 우선 재사용합니다.
 
---
 
## 3. Accessibility
누구나 쉽게 사용할 수 있어야 합니다.
- 충분한 색상 대비 (WCAG 2.1 AA 기준 준수)
- 읽기 쉬운 폰트
- 큰 클릭 영역
- 키보드 접근성
- 모바일 환경 고려
색상만으로 의미를 전달하지 않습니다.
 
---
 
## 4. Mobile First
모든 화면은 Mobile을 기준으로 설계합니다.
Desktop은 Mobile을 확장하는 방식으로 구현합니다.
 
지원 환경
- Mobile
- Tablet
- Desktop
지원 Breakpoint: Mobile / Tablet / Desktop
(구체적인 px 수치는 spacing.md 참조)
 
Dark mode는 MVP 범위에서 제외합니다.
 
---
 
## 5. Global Usability (외국인 사용자 고려)
UYOU의 핵심 사용자는 한국어에 익숙하지 않은 외국인입니다.
언어 장벽을 최소화하는 디자인을 우선합니다.
 
- **텍스트 길이 가변성**: 번역 시 언어별 텍스트 길이가 달라질 수 있음을 전제로 레이아웃을 설계합니다. (버튼, 카드, 내비게이션 등에서 줄바꿈/잘림 대응)
- **다국어 가독성**: 한글과 라틴 문자를 함께 고려한 폰트 및 타이포그래피를 사용합니다. (세부 기준은 typography.md 참조)
- **비주얼 우선 전달**: 텍스트만으로 정보를 전달하지 않고, 아이콘·이미지·시각적 단서를 적극 활용하여 언어 장벽을 낮춥니다.
- **쉬운 언어 사용**: 전문 용어나 한국 교육 특유의 표현은 최대한 쉬운 언어로 풀어 설명합니다. (용어 정리는 별도 glossary 문서 참조)
---
 
# Visual Style
UYOU의 전체적인 분위기는 다음과 같습니다.
- 밝고 깔끔한 UI
- 신뢰감 있는 브랜드 이미지
- 충분한 여백
- 직관적인 정보 구조
복잡한 배경이나 과도한 장식은 사용하지 않습니다.
 
---
 
# Voice & Tone
- 쉬운 단어와 짧은 문장을 사용합니다.
- 전문 용어, 한국 교육 특유의 축약어는 최소화하거나 풀어서 설명합니다.
- 친절하고 신뢰감 있는 어조를 유지합니다.

# 컴포넌트 원칙
공통 컴포넌트를 우선 사용합니다.
 
우선순위
1. shadcn/ui
2. 프로젝트 공통 컴포넌트
3. 새로운 컴포넌트 생성
새로운 컴포넌트를 만들기 전에 기존 컴포넌트를 재사용할 수 있는지 먼저 검토합니다.
 
---
 
# 반응형 원칙
모든 페이지는 Mobile First 방식으로 설계합니다.
레이아웃은 화면 크기에 따라 자연스럽게 확장되어야 합니다.
 
---
 
# AI 구현 규칙
UI를 구현할 때 반드시 다음 규칙을 따릅니다.
- Design System을 준수합니다.
- 기존 컴포넌트를 우선 재사용합니다.
- shadcn/ui를 우선 사용합니다.
- 새로운 디자인 규칙을 임의로 추가하지 않습니다.
- Tailwind CSS를 사용합니다.
- Mobile First를 유지합니다.
- 접근성을 고려합니다.
- 일관성을 가장 중요하게 생각합니다.
- 다국어 사용자를 고려한 레이아웃 유연성을 유지합니다.
---
 
# 하지 않는 것 (Anti-pattern)
- 임의의 색상 코드/px 값을 만들지 않는다 (정의된 토큰만 사용)
- 페이지마다 다른 버튼 스타일을 만들지 않는다
- 장식 목적의 애니메이션을 과도하게 사용하지 않는다
- 정보 없이 이미지/배경만으로 섹션을 채우지 않는다
- 텍스트 잘림/줄바꿈을 고려하지 않은 고정폭 레이아웃을 만들지 않는다
- 색상만으로 상태(성공/실패/경고 등)를 구분하지 않는다
