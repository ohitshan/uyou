# 메인 페이지 ('/') 디자인 및 기획

## 디자인 컨셉
- 깔끔하고 현대적인 (Clean & Modern) UI
- 사용자 중심의 직관적인 정보 전달

## 구성 요소
1. **히어로 섹션 (Hero Section)**
   - 페이지 최상단 배치.
   - 메인 배너 중앙에 **문의하기 버튼** 배치.
   - 버튼은 현재 라우팅/외부 링크 없이 UI 요소로 우선 구현.

2. **대학 리스트 섹션 (University List)**
   - 히어로 섹션 하단에 배치.
   - **데이터 소스**: `/api/university-list` API 호출 결과.
   - API는 Supabase `university_info` 테이블에서 `university_name`을 조회하여 리스트를 반환.
   - **레이아웃**: 카드 그리드 형태.
   - 초기 구현 대상 대학은 **가천대학교**.
   - 향후 여러 대학이 추가될 수 있도록 리스트 구조로 유지.

## 디자인 가이드라인
- 모든 간격 및 크기는 4px 또는 6px 배수 적용.
